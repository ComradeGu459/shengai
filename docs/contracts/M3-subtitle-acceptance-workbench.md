# M3 S5 字幕验收工作台契约

状态：规划冻结，进入 UI / 后端并行实现  
日期：2026-08-15

## 1. 目标

S5 继承本地“字幕验收工作台”的核心生产能力，把不可变待验收台词修订、可选画面字版本和项目视频装载到同一验收会话中。员工可按集播放和精确定位，在共享时间标尺上检查、轻量修改、记录问题、返工并完成逐集或整剧验收，最后把会话推进到 `ready_to_release`，交由 S7 的唯一交付命令原子固定验收版本与交付产品。

S5 不重跑 ASR/OCR，不覆盖 S3/S4 历史版本，也不把浏览器内存、查询缓存或本地文件当作业务权威。

## 2. 已确认产品方向

- 界面沿用本地应用的“专业编辑套件”方向：左侧剧集与筛选，中间视频和多轨时间轴，右侧字幕编辑与问题详情。
- 自动联动为默认入口：读取当前项目最新有效的 S3 台词修订、可选 S4 画面字版本、术语版本和素材清单；同时保留明确的版本选择入口，刷新不得偷偷切换来源。
- 同集优先播放有画面字版视频，不存在时回退到无画面字版；只显示真实存在的版本，切换只改变验收视图，不改源文件。
- 台词轨、画面字轨、问题轨共享时间标尺；真实重叠或共用端点按占帧规则动态排层，空画面字轨收起。
- 允许轻量但完整的字幕修改：文字、入点、出点、整条移动、新增、删除、多选、复制、剪切、粘贴、撤销和恢复。
- 允许逐帧、跳转、拖动、缩放和平移；快捷键不得劫持文本输入框的原生编辑行为。
- 逐集“通过并下一集”；整剧预检后可一键通过无硬错误的剩余集。硬错误必须逐集处理，不能静默放行。
- 返工只选择受影响集和轨道，形成可追踪返工请求；不得要求重新导入整部剧，也不得覆盖已冻结验收版本。
- 项目中心是唯一跨项目选择入口：可搜索并打开任意 `active` 云端项目，再进入该项目的字幕验收；工作台只提供返回/切换项目入口，不复制另一套项目列表。进入项目后恢复唯一可写会话，并允许选择历史会话只读查看。
- “字幕”页内部必须区分全部、台词和画面字。新增必须显式选择“新增台词”或“新增画面字”，不得由含糊按钮静默默认轨道；`Ctrl+N` 在“全部”筛选下也必须先明确目标轨道。

## 3. 唯一数据所有者

PostgreSQL 是验收会话、来源快照、逐集状态、Cue 工作副本、编辑事件、问题、返工请求和不可变验收版本的唯一权威。所有写命令必须带项目范围、期望修订和幂等键。网络未知结果只能用同一完整请求身份恢复；确定性冲突重新读取权威状态后，下一次显式提交使用新请求身份。

## 4. 来源与失效

创建会话固定最新有效 S3 台词 Release、同项目可选 S4 画面字 Release、当前素材清单、逐集可用视频 Asset、术语版本和规则版本。任一来源被替换、项目进入回收/清理或素材摘要变化，当前会话转为 `stale`。旧会话与历史版本只读可查，唯一写入口是“从新来源新建验收会话”。

## 5. 状态模型

会话状态为 `draft / preflighting / ready_to_release / released / stale / blocked`；逐集状态为 `not_started / in_review / changes_pending / blocked / rework_required / passed`。已通过集发生 Cue、问题或视频选择变化时，通过签名立即失效并回到 `changes_pending`。交付资格只由服务端派生；S5 不提供独立发布写命令。

## 6. 多轨与播放

- 轨道为 `dialogue / screen_text / issue`，共享整数毫秒时间标尺。
- Cue 必须满足 `0 <= startMs < endMs <= authoritativeDurationMs`；未知时长可查看但不能通过或进入交付确认。
- 视频、播放头、字幕叠层、编辑器和问题定位使用同一当前时间。
- 有画面字版优先、无画面字版回退；切换只保存验收选择，不改 Asset。
- 首轮复用现有有界媒体授权。360p/1080p 兼容代理作为 S5 后续媒体子切片，保持原 Asset 与代理绑定、当前集优先和失败回退；未生成时如实显示能力状态。

## 7. 编辑、撤销与自动保存

- 文字、时间、移动、缩放、新增、删除、复制、剪切、粘贴、撤销和恢复均形成条件写命令与不可变事件。
- 在播放头新增默认持续 2 秒，并裁切到权威视频结尾；若剩余时长不足安全最小时长则阻止创建并说明原因。新增后定位新 Cue 并进入其编辑上下文。
- 删除支持单条和多选，确认信息必须说明只删除当前验收工作副本，不修改上游 SRT、源视频或不可变历史版本。
- 移动 Cue 保持原时长；左右边缘分别修改入点和出点。
- 多选粘贴保留相对时间与轨道；跨轨粘贴必须显式选择目标轨道。
- 保存失败不得展示“已保存”，必须保留未提交提示、请求标识和唯一恢复动作。
- 文本框聚焦时，复制、剪切、粘贴、全选、撤销和恢复保持浏览器原生文字编辑语义。

## 8. 质量检查与问题

确定性检查至少覆盖同轨重叠、共用端点、非法时间、越过视频时长、空文字、时长/间隔异常、禁止格式标签、已确认中文标点规则、来源/视频缺失和画面字配对不完整。`error` 阻断通过和交付；`warning` 可带理由确认。人工问题可记录当前时间、轨道、类型、备注和状态。完整人脸身份、复杂内容风险和模型判断继续作为独立风险审查模块。

## 9. 验收、返工与冻结

- “通过并下一集”在事务中完成当前集检查、保存签名并进入下一未通过集。
- 整剧预检返回逐集结果和可通过集合；一键通过只处理无硬错误、来源有效且证据完整的集。
- 返工请求选择集数、`dialogue / screen_text` 轨道和原因；未选集不受影响。
- 上游完成返工后从新来源新建会话，旧会话和返工链路保留。
- S5 只把整剧推进到 `ready_to_release`，不暴露独立创建 `AcceptanceRelease` 的写接口。
- S7 的唯一幂等交付命令在同一事务中固定 `AcceptanceRelease + DeliveryProduct + DeliveryManifest`；生成 Worker 成功后再把会话推进到 `released`。
- S5 可继续只读列出由 S7 生成的历史 `AcceptanceRelease`，但历史读取不得创建、重建或改变发布状态。

## 10. UI 必须覆盖

- 项目/来源状态、整剧进度、异常/提醒和扫描状态；
- 返回项目中心/切换项目、当前项目身份、当前可写会话与历史只读会话选择；
- 左侧集列表及全部/有画面字/多层/问题集筛选；
- 中间视频、版本切换、播放控制和多轨时间轴；
- 右侧“字幕 / 问题”一级页签；字幕页内的全部/台词/画面字筛选、明确双新增、删除、多选剪贴板、编辑器；问题页内的人工记录、处理和定位；
- 加载、空数据、blocked/stale、媒体不可用、保存/预检/交付入口失败和刷新恢复；
- 1440×900、1024×768、侧栏 204/72 两态；根页面不横溢；
- 弹窗/抽屉焦点、键盘闭环、失败恢复和提交中防重复。

## 11. 任务拆分

1. `UI-M3-05`：完整设计、交互原型和验收矩阵，不修改生产前端。
2. `BACK-M3-05A`：共享契约、迁移、状态机、质量检查、编辑事件、返工和交付就绪门禁；不可变 Release 仅由 S7 原子交付命令创建。
3. `FRONT-M3-05B`：UI 与后端通过规划审查后实现正式 React 页面。
4. `S5-MEDIA`：核心闭环可用后补 360p/1080p 代理、当前集优先和失败回退，不改验收语义。
5. `BACK-M3-05C`：不改接口与迁移，只补双轨新增、删除、剪贴板和撤销恢复的后端高价值闭环验证。

## 12. 非目标与授权边界

不接真实 ASR/OCR、密钥、付费或外网；不做完整人脸风险、管理员控制台、S7 产品库和甲方上传；不购买或部署云资源；不提交、推送；不删除或覆盖任何上游版本、源字幕和源视频。

## 13. 关闭门

- `LOCAL_APP_PARITY.md` 写回本地能力的云端实现、差异和证据；
- 后端在精确隔离 PostgreSQL 覆盖幂等、并发、来源失效、编辑恢复、返工、逐集/整剧检查，以及 S5 `ready_to_release` 到 S7 原子 Release/产品生成的唯一衔接；
- 正式 React 通过同状态高保真、真实浏览器主链路、关键失败恢复、1440/1024 和键盘验收；
- S5 关闭时由规划只运行一次完整 `pnpm check`，P0/P1 必须为 0。
