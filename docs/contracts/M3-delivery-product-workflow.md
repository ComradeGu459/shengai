# M3 S7 交付确认与交付产品库契约

状态：用户已确认产品方向，进入 UI 设计冻结

## 1. 目标

把旧本地双软件中的“验收冻结 → 返回另一软件 → 统一导出”收敛成云端一站式交付：员工在视频字幕验收工作台完成修改和整剧预检后，进入一张完整的交付确认页；确认后由服务端幂等生成不可变验收快照、正式交付文件和产品记录，再进入独立的全局交付产品库。

员工不再单独理解或执行“冻结”，也不返回本地软件。`AcceptanceRelease` 仍作为后台不可变安全边界，防止已经交付的文件被后续编辑覆盖。

## 2. 页面与路由边界

1. `/projects/:projectId/subtitle-acceptance`：继续负责看片、双轨轻量修改、问题、逐集通过和整剧预检；达到服务端就绪状态后唯一下一步为“前往交付确认”。
2. `/projects/:projectId/deliveries/confirm?sessionId=...`：完整交付确认页，只读取当前验收会话、来源、术语模板和服务端预检事实；不编辑字幕、画面字或术语正文。
3. `/deliveries`：全局独立“交付产品库”，与项目中心、任务中心同级，跨项目搜索、筛选、排序和进入详情。
4. `/deliveries/:deliveryId`：交付产品详情，展示不可变文件、来源版本、负责人、备注、时间和后续外部上传扩展位。

项目工作台不再增加第二套交付产品列表；项目上下文只提供进入本项目交付确认或跳转到全局产品库并按当前项目筛选的入口。

## 3. 唯一用户流程

1. 员工在 S5 完成逐集处理。
2. 整剧预检成功且服务端返回全部集通过、无 open issue、来源有效。
3. 员工进入完整交付确认页，核对产品名称、来源版本、负责人、备注和三类文件摘要。
4. 员工执行唯一主操作“生成交付产品”。该命令使用一个稳定 `deliveryId`、完整请求体和幂等键。
5. 服务端原子固定 `AcceptanceRelease + DeliveryProduct + DeliveryManifest`，随后幂等生成对象存储文件；浏览器不串联两个不可恢复的创建请求。
6. 成功页显示产品名称与三类文件，提供“立即进入产品详情”；默认短暂倒计时后自动进入，用户可提前点击或取消自动进入。
7. 需要修改时从产品详情执行“创建修订”，基于已交付来源建立新的验收工作副本；旧产品和旧文件保持不可变。

小问题在交付前留在 S5 直接修改；整集或批量结构性问题才创建上游返工。交付成功后不返回另一个本地软件。

## 4. 交付确认页

确认页是完整页面，不使用侧抽屉。首屏必须清楚展示：

- 项目与产品名，产品顶层命名为 `剧名-V1`、`剧名-V2`；版本由服务端按项目确定，浏览器不得猜测。
- 当前负责人和可编辑备注；账号未启用前负责人读取项目现有负责人事实，不伪造成员选择器。
- 验收会话修订、通过集数、阻断集数、S3 台词 Release、可选 S4 画面字 Release、视频清单版本、术语版本和术语导出模板版本。
- 台词 SRT：集数、Cue 数、UTF-8 BOM 与命名摘要。
- 画面字 SRT：集数、非空集数、Cue 数和空轨说明。
- 术语 XLSX：术语数量、模板名称/版本和五字段表头摘要。
- “返回继续修改”和唯一主操作“生成交付产品”。

确认页只允许预览，不允许在此编辑字幕或术语。发现问题时使用明确来源链接返回对应模块；来源变化后原确认事实失效，必须重新读取。

## 5. 正式文件结构

产品顶层目录为 `剧名-Vn`，内部不重复嵌套版本号：

```text
剧名-V1/
  台词字幕/
    第01集.srt
    ...
  画面字/
    第01集.srt
    ...
  术语表/
    剧名_术语表.xlsx
```

- 每一集始终生成对应台词 SRT 与画面字 SRT，便于按集稳定配对。
- 某集没有画面字时，该集仍生成 UTF-8 BOM 的合法空 SRT；整剧完全没有画面字时，全部集的画面字文件均为空轨，并在产品详情标记“空轨文件 / 0 条”，不能表现为漏文件。
- 术语 XLSX 绑定生成时的不可变 `TermVersion + TemplateVersion`；确认页只预览，不临时修改模板。
- “下载全部”可以生成传输用 ZIP，但 ZIP 不是第四类正式交付内容，三类产品事实仍以上述目录为准。

## 6. 状态与唯一权威

PostgreSQL 是产品、文件清单、来源绑定、负责人、备注、生成 Attempt 和状态的唯一权威；对象存储保存不可变文件字节。建议首期状态：

- `preparing`：已接受创建意图，正在固定快照或生成文件。
- `ready`：三类文件及清单均已校验，可以下载。
- `generation_failed`：生成未完成，保留原因、requestId 和同一产品恢复入口。
- `recycled`：产品记录进入可恢复回收状态；永久清理另立生命周期任务。

未知结果只能按已知 `deliveryId` 查询本次结果，不重发另一条创建命令。生成失败只能恢复同一产品和同一文件清单，不创建 V2。只有员工明确“创建修订”且完成新一轮验收后，才生成下一产品版本。

文件内容不可更新；负责人、备注、未来外部上传状态等元数据可更新并改变 `updatedAt`。列表的“更新时间”不得暗示不可变文件已被改写。

## 7. 全局交付产品库

列表采用成熟数据表而非卡片墙，首期字段为：

- 产品名称
- 项目
- 版本
- 状态
- 文件摘要
- 负责人
- 备注摘要
- 创建时间
- 更新时间
- 操作

支持服务端搜索产品名/项目名/负责人/备注，按状态筛选，按创建时间或更新时间排序，稳定分页。行级主操作只有“查看详情”；下载、修改备注和回收等低频动作进入详情或三点菜单。批量下载/回收后续有真实需求再启用，不在首版制造复杂批量栏。

详情页展示产品身份、生成状态、三类文件树、单独下载/下载全部、来源版本、创建/更新时间、负责人、备注、生成请求标识和历史事件。字幕、画面字、术语内容不可在产品库中编辑。

## 8. 成功、失败与焦点

- 创建提交中锁定返回、重复提交和来源切换，焦点留在可编程主内容语境；不展示虚假百分比，只显示真实阶段。
- 确定失败保留全部确认内容、原因和 requestId；可修复来源问题时提供唯一返回入口。
- 网络未知显示“查询本次生成结果”，只 GET 同一 `deliveryId`。
- 成功页先给出产品名称和三类文件完成事实，焦点进入成功标题；主按钮“立即进入产品详情”，自动进入倒计时可以取消且不抢走键盘用户焦点。
- 所有确认、恢复和回收弹窗遵循 Tab/Shift+Tab 闭环、非提交 Escape/遮罩关闭回触发点、提交中锁定和失败后安全焦点。

## 9. 当前非目标

- 不自动上传甲方总库；外部上传必须是未来独立命令、权限和审计。
- 不增加管理员批准门；当前仍由负责该剧的员工直接生成内部正式产品。
- 不在产品库重跑 ASR/OCR、编辑字幕、修改术语或覆盖历史文件。
- 不接真实云资源、外部网络、密钥、付费或部署。

## 10. 关闭门

S7 首期至少证明：

1. 从服务端就绪的验收会话进入完整确认页，刷新仍恢复同一来源和产品意图。
2. 一次命令形成唯一 `AcceptanceRelease`、产品、文件清单和稳定版本；未知结果不产生重复产品。
3. 一部多集匿名剧生成每集台词/画面字 SRT 和一个术语 XLSX；空画面字集仍有合法空 SRT。
4. 产品库支持服务端搜索、状态筛选、创建/更新时间排序、分页和详情恢复。
5. 文件下载字节确定，历史产品不因新修订或备注更新而变化。
6. 1440×900 与 1024×768 无根页面横溢；加载、空、生成中、失败、未知、成功、只读和键盘焦点均有正式证据。
