# M3 内部可用工作台快速冲刺

日期窗口：2026-08-13 至 2026-08-27  
目标性质：2026-08-27 是最晚内部可用日期，不是必须耗满的工期；任何达到质量门的可工作增量立即交付预览和试用。

## 1. 成功标准

使用匿名或获准测试素材，至少完整跑通：

`已上传公司 SRT / 视频 → 术语候选 → 人工裁决并确认版本 → ASR 与画面字 OCR → 公司稿/ASR 对照 → 画面字人工确认 → 字幕验收 → 导出台词 SRT、画面字 SRT 与术语 XLSX`

内部可用版必须保存后端权威状态，刷新后可恢复；原始公司稿、ASR 原文和人工采纳稿分开保存；真实付费调用可审计、幂等且不会无限重试。

## 2. 最快交付节奏

以下是最晚检查点，不要求等待到对应日期：

| 最晚检查点 | 可工作增量 |
| --- | --- |
| 第 2 天 | 项目工作台外壳与术语正式 UI 方向可预览 |
| 第 5 天 | 一部测试剧可从已上传 SRT 生成候选、人工裁决、确认术语版本并导出 XLSX |
| 第 7 天 | 至少一集通过 ASR fake/已确认适配契约进入前置审改对照 |
| 第 10 天 | 至少一集可完成公司稿/ASR 采纳、人工修改与 SRT 导出 |

若真实 ASR 凭据或费用授权未及时到位，第 7 天前使用无付费副作用的适配器 fake 固定接口和业务状态；这不阻塞术语与审改开发，但内部正式试用前必须用一个获准供应商和少量样本完成真实调用验收。

## 3. 纵向切片

1. **S1 术语确认**：读取已上传公司 SRT；候选、证据、人工新增/修改/驳回、当前页与跨页全选、全部采用并导出、全部裁决门禁、不可变版本、公司级版本化五字段模板和 XLSX 导出。产品与数据权威见 `docs/contracts/M3-terms-workflow.md`。
2. **S2 ASR 批次（Wave A 与 Wave B 均已关闭）**：固定术语版本与视频 Asset 双门禁；整剧/选中集/单集、确定性 fake、批次状态、租约、取消、子集重试、不可变结果、幂等和零费用用量；S2.1 增加权威热词预览/发送证据、项目中心多剧发起、全局 Dispatch 汇总、公平并发和费用分层。单剧与多剧均已通过正式 UI 终验和精确隔离库完整集成检查。权威契约见 `docs/contracts/M3-asr-batch.md` 与 `docs/contracts/M3-asr-bulk-dispatch.md`；真实供应商另过授权门。
3. **S3 前置审改最小闭环（已关闭）**：只读公司稿、只读 ASR、一对一/一对多/多对一对齐、逐条唯一采纳稿、整剧/选中集/单条文本基准、六类决定与撤销、视频时间定位、格式门禁和待验收 SRT 导出。正式 UI、后端与 React 已通过完整质量门；权威契约见 `docs/contracts/M3-pre-edit-workbench.md`。
4. **S4 画面字 OCR 工作台（已关闭）**：固定术语版本与 `screen_video` Asset 双门禁；整剧/选中集/单集、确定性零网络 Adapter、抽帧/去重证据、逐集状态、失败集重试、候选人工裁决、文字/时间修改、左右双轴、明确空集、来源/证据失效保护和不可变画面字 SRT 均已通过正式 UI 终验与完整质量门。权威契约见 `docs/contracts/M3-screen-text-workflow.md`；真实 OCR 厂商另过授权门。
5. **S5 视频字幕验收工作台**：读取不可变待验收台词修订和画面字版本，结合视频执行多轨定位、轻量文字/时间修改、逐集/整剧验收、返工和冻结版本；不重跑识别。
6. **S6 单剧全流程联调**：一部测试剧连续运行；刷新恢复、失败重试、费用防重复、来源失效、数据清理、完整 `pnpm check` 和真实浏览器主流程。
7. **S7 交付产品库**：从有效冻结验收版本生成、归档、搜索和下载台词 SRT、画面字 SRT 与术语 XLSX；甲方总库自动上传另行授权。

UI 与后端在同一切片的产品输入和数据语义确认后并行；前端可在后端契约冻结、UI 核心结构稳定时开始集成，不等待无关的视觉细节。规划收件 FIFO 只串行审核交接，不串行阻塞已经解锁的执行任务。

## 4. 不可压缩的质量底线

- PostgreSQL 是术语版本、ASR 批次和人工采纳稿的唯一权威来源。
- 原始 SRT、ASR 原文和已确认术语版本不可被静默覆盖。
- 付费 ASR 使用稳定幂等键、供应商请求标识、用量记录和有限重试；未知结果不能自动重复付费。
- 刷新后可以读取已提交状态；失败必须保留原因和下一动作。
- 发布前关闭所有 P0/P1；P2 必须有明确延期记录，P3 不阻塞内部可用版。
- 每个切片返工只跑定向验证；切片关闭和内部发布运行完整检查；关键异步失败与浏览器交互必须有真实或经规划记录的等价证据。

## 5. 首期非目标

- 账号、组织、管理员审批和多租户。
- 真实 OCR 供应商、字幕验收工作台、交付产品库完整管理、甲方总库自动上传；画面字 OCR 的零网络功能闭环已经进入 S4。
- 人脸身份、复杂内容风险和模型蒸馏。
- 自建 ASR GPU 模型、真实 R2 迁移、极限容量压测和正式公网发布。
- 跨项目学习库前台；只保留未来结构化学习事件兼容边界。

## 6. 进度与调整

- 进度只按“能否跑通一部剧/一集”的可工作结果计算，不按文档数、页面数或测试数计算。
- 规划按 `docs/WORKFLOW.md` 12.3 做阶段简报；任一角色可按 12.4 提出协作改进建议。
- 提前完成的切片立即进入下一个切片；预计延误超过半天时，规划先削减 P2/P3 或非目标，不削减数据正确性、幂等、恢复和核心验收。
