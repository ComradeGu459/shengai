## 验收结论

- 新建预算策略只接受人民币规则；历史多币种事实仍可只读审计，但不参与当前预算主账本。
- 人民币原生计费不依赖换算快照；外币报价必须绑定不可变换算快照，按数据库精确十进制计算并向上取整到 6 位后写入人民币事实。
- 当前预算预留、结算、总览和用量列表只汇总人民币事实；缺失、过期或未知换算不会补零，也不会在浏览器换算。
- 外币引擎的预算覆盖由“人民币规则 + 有效换算快照”共同决定；缺失换算以独立原因呈现，不再错误要求美元预算规则。
- 管理员预算页面只创建 ASR/OCR 的人民币日/月规则，原始币种仅作为审计信息。
