# S6 真实素材冒烟验收矩阵

状态：用户已确认，规划冻结  
任务：`TEST-S6-02 Rev 2`  
样本：第 1、14、26 集，共 3 个 MP4 + 3 个 SRT，约 346.8 MB  

## 1. 本轮要回答的问题

1. 三集真实文件字节能否完成扫描、素材配对、分片上传、Asset 绑定和刷新恢复。
2. 真实 9:16/高分辨率视频能否取得只读播放授权并在正式页面正确 `contain` 播放。
3. 真实公司 SRT 能否进入术语、零网络 ASR/OCR、前置审改、字幕验收和交付产品链，而不依赖前端假数据或浏览器旧状态。
4. 最终台词 SRT、画面字 SRT、术语 XLSX 能否生成、下载、解析，并保持集数、时间轴、编码、摘要和文件身份一致。

本轮不回答真实 ASR/OCR 准确率、热词命中率、供应商时延、费用或公网并发；这些必须在真实供应商接入后单独验收。

## 2. 数据与安全边界

- 原始根目录固定为 `E:\七猫兼职\02_项目\05_妈妈是神在人间的分神\原始素材`；只读取 `视频/1.mp4`、`视频/14.mp4`、`视频/26.mp4` 与 `srt/1.srt`、`srt/14.srt`、`srt/26.srt`。
- 原始文件绝不修改、移动、重命名、删除或生成旁路文件；开始和结束分别核对六个文件的大小、修改时间和只读摘要。
- 真实文件字节、字幕正文、帧图、下载产品和数据库只能存在于本轮隔离数据库、临时对象存储或系统临时目录；不得写入仓库、日志、测试夹具、截图正文或 Git。
- 数据库名使用 `qimao_test_s6_02_<时间/随机后缀>`；临时对象/输出目录使用同一前缀，完成后精确验证 `1→0`。
- 只使用现有零网络 Adapter；禁止真实供应商、密钥、付费、云资源、外部网络、部署、提交或推送。
- 测试角色不修改生产 frontend/backend、迁移、共享契约或 DESIGN。发现问题建立 `QA-S6-02-*` 并只交规划。

## 3. 真实文件摄取

1. 从空隔离数据库应用全部迁移，启动正式 Fastify、Worker 和 React；端口启动前确认空闲。
2. 创建匿名项目 `S6-真实三集冒烟`；真实项目名不得进入数据库项目名、页面标题、截图或报告。
3. 扫描六个文件并确认每集同一 MP4 绑定 `asr_video + screen_video`、SRT 绑定 `company_srt`：6 个物理文件、9 个角色绑定。
4. 使用正式上传协议读取并分块上传真实字节；验证缺失分片、续传、指纹、SHA-256、大小、完成幂等和单 MP4 共享绑定。不得通过数据库直接伪造已上传 Asset。
5. 刷新/重启前端后从 API 恢复相同 Upload/Asset/Manifest 身份；随机抽查一个 Range/只读对象读取，其字节摘要与源文件对应片段一致。
6. 记录每个文件上传耗时、总字节和失败恢复次数，仅作为本机冒烟数据，不推断生产带宽或服务器容量。

## 4. 播放与真实来源

1. 第 1、14、26 集分别取得短时只读播放授权；验证项目/Asset/对象归属、摘要和大小门禁。
2. 正式 React 至少播放三集各一个片段；第 14 集 2160×3840 与其他 1080×1920 均保持竖屏 `object-fit: contain`，播放/暂停、进度、音量、倍速、前后 1 秒、逐帧和放大入口可用。
3. 切集、切 Asset、刷新和授权过期后不得播放旧对象；错误必须显示原因/requestId 和唯一恢复动作。
4. 证据截图必须遮蔽字幕正文和视频画面，仅保留几何框、状态、控制器和匿名 ID。

## 5. 跨模块业务链

1. 解析三份真实公司 SRT，核对 cue 数量、时间单调性、结束时间不超过对应视频时长；不在报告中记录正文。
2. 生成术语候选并完成最小人工裁决，发布不可变术语版本与五字段模板；仅记录候选/确认数量和版本摘要。
3. 运行零网络 ASR/OCR 三集任务，确认其明确标记模拟/零网络事实、Attempt/Usage/热词版本/刷新恢复成立；禁止把模拟结果描述成识别准确。
4. 创建前置审改会话，验证公司 SRT、模拟 ASR、术语版本、视频 Asset 均来自正式上游 ID/摘要；完成最小合法决定与不可变修订。
5. 创建字幕验收会话，验证台词/画面字双轨、新增/删除/剪贴、同步预检、三集通过和 `ready_to_release`；不得跳过门禁直接改数据库状态。
6. 从独立交付确认页使用稳定 `deliveryId` 生成同一产品；验证未知结果只查询同一 ID，失败恢复不创建第二产品。
7. 从全局产品库刷新发现同一产品，下载三集台词 SRT、三集画面字 SRT和一个术语 XLSX。若画面字无条目，必须为 UTF-8 BOM 合法空 SRT。

## 6. 交付文件验收

- 文件树与 manifest 数量一致，文件名/集数无重复、无漏集，下载身份绑定同一 deliveryId。
- 所有 SRT 可解析、编号连续、时间轴合法；台词轨不为空，画面字轨允许明确空轨。
- UTF-8/BOM 规则与合同一致；空画面字轨必须恰好满足合法空文件规则。
- XLSX 可打开并包含固定五字段模板；只记录行数、表头和版本，不记录真实术语正文。
- 下载前后摘要与大小一致；数据库只保存对象身份/摘要/大小，不保存正式文件字节。

## 7. 流畅性与多项目隔离

### 7.1 流畅性冒烟门

- 三个真实 MP4 上传期间，上传任务页必须持续响应搜索、筛选、展开详情、暂停/继续、切换项目和侧栏收起；不得出现持续白屏、整页冻结、重复提交或进度倒退。
- 使用浏览器 Performance/Long Task 证据记录上传中和项目切换各一段操作：单次主线程长任务超过 200 ms 必须说明来源，超过 500 ms 或连续阻塞 1 秒按 P1 处理；不得只凭主观“感觉流畅”。
- 本地正常链下，点击后应在 1 秒内出现可见反馈，项目数据/路由应在 3 秒内稳定；超过目标需记录页面、动作、耗时、CPU/网络环境和是否可重复，不把本机数据冒充生产 SLA。
- 三集播放器分别验证首次载入、播放/暂停、拖动、前后 1 秒、逐帧、倍速和放大；控件反馈不应被 4K 解码长期阻塞，发生浏览器解码限制时如实显示兼容阻断。
- 上传、Worker 或下载在后台运行时，页面刷新/返回后只从后端权威状态恢复；前端不得通过高频轮询、同步摘要计算或重复读取全部文件造成明显卡顿。

### 7.2 项目隔离与切换

- 除真实素材项目 A 外，创建匿名项目 B；B 使用空项目或系统临时目录中的最小匿名夹具，不复制真实字幕正文、视频帧或真实项目名称。
- 在 A 上传中、上传完成、识别处理中、审改有脏状态和交付 ready 五个阶段分别执行 A→B→A；至少完成 5 轮切换。每轮核对 URL/projectId、标题、素材/任务/版本/产品数量和请求参数均属于当前项目。
- A 的上传/Worker 可在后台继续，但 B 页面不得出现 A 的文件名、进度、候选、术语、媒体、任务、错误、requestId、选择状态或成功提示；返回 A 后从后端恢复原进度，不重新创建任务。
- 切换项目必须清空普通选择、跨页全选、打开抽屉/弹窗和旧媒体授权；若当前有未保存审改/字幕修改，必须出现明确离开门禁，禁止静默丢失。
- A 的迟到查询/命令响应不得覆盖 B 的 UI；至少用一项可控延迟验证 A 响应在切到 B 后被丢弃。网络未知恢复仍绑定原 projectId + 原业务 ID + 原幂等键。
- 通过 B 的项目路由读取 A 的 Upload/Asset/术语/ASR/OCR/审改/验收/Delivery/文件下载必须被服务端拒绝且不泄露对象键、真实路径或正文；反向 A→B 同样抽查。
- 全局任务/产品列表可以同时出现 A/B，但每一行身份、项目名、状态、链接和详情必须对应其所属项目；项目内页面不得借全局列表形成跨项目写入口。
