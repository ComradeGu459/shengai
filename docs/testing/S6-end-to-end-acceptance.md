## 1. 授权与数据边界

- 原始素材固定为 `E:\七猫兼职\02_项目\05_妈妈是神在人间的分神\原始素材`，只允许读取对应 `视频/<集数>.mp4` 与 `srt/<集数>.srt`。
- 禁止修改、移动、重命名、删除或覆盖原始目录中的任何内容；禁止把真实字幕正文、视频帧或业务名称写入源码、测试夹具、Git 文档或日志。
- 允许为本轮创建隔离测试数据库、临时对象、浏览器上传会话、测试输出和仓库外证据；完成后只清理本轮创建的精确对象，不清理默认库或其他任务服务。
- 本轮只使用仓库现有零网络 ASR/OCR/AI 适配器，不接真实供应商、密钥、付费、云资源或外部网络；结果只验证业务链和恢复能力，不评价真实识别准确率。
- 代码、协议或页面出现缺陷时停止受影响动作并形成 `QA-S6-*` 缺陷包；测试对话不得直接修改生产代码。

## 2. 隔离与命名

- 数据库名称必须包含 `qimao_test_s6_01_` 与本轮时间/随机后缀；从空库应用全部迁移。
- 测试项目显示名使用匿名别名 `S6-三集联调`，数据库内不得保存原项目文件夹名称作为项目名。
- 服务端口必须在启动前验证空闲并写入测试报告；不得占用或停止其他任务已声明的端口。
- 仓库外证据使用测试对话自己的可视化目录；截图优先遮蔽字幕正文，只保留状态、布局、请求标识和必要几何证据。
- 测试报告固定写入 `docs/testing/S6-end-to-end-report.md`，只记录匿名事实、ID 摘要、状态码、数量和证据路径，不复制真实台词。

## 3. 正常主链

1. 创建匿名项目并验证刷新恢复。
2. 扫描三集素材：每集一个 MP4 同时绑定 `asr_video + screen_video`，一个 SRT 绑定 `company_srt`；确认 6 个物理文件、9 个素材角色绑定，不重复上传共享 MP4。
3. 完成上传与 Asset 绑定；验证刷新后只读取后端权威会话/Asset，不依赖浏览器旧状态。
4. 从三集公司 SRT 生成术语候选，完成最小人工裁决、确认不可变术语版本并绑定五字段模板；报告只记录数量，不记录术语正文。
5. 使用零网络 Adapter 发起三集 ASR，验证术语版本/视频双门禁、逐集结果、Attempt/Usage、刷新恢复和无付费事实。
6. 使用零网络 Adapter 发起三集画面字任务，覆盖普通 1080×1920 与第 14 集 2160×3840；验证证据不可用时的诚实阻断、候选/明确空集和不可变画面字版本。
7. 创建前置审改会话，证明公司稿、ASR 和固定术语版本来自正式上游 ID/摘要；完成最小决定、格式门禁和不可变待验收修订。
8. 创建字幕验收会话，验证 9:16 `contain`、台词/画面字双轨、同步预检、逐集/整剧通过和交付就绪事实；不在 S5 直接冻结或下载。
9. 进入独立交付确认页，以稳定 `deliveryId` 生成每集台词 SRT、每集画面字 SRT 和全剧术语 XLSX；画面字为空时验证 UTF-8 BOM 合法空轨。
10. 从全局产品库刷新发现同一产品，进入详情并下载；核对文件数量、摘要、大小和历史事件，不把文件字节写入仓库。

## 4. 跨模块与恢复矩阵

- 每个模块交接至少保存并核对上游 ID、版本和摘要；刷新后由正式 API 重新发现。
- 至少在上传、ASR/OCR、前置审改、字幕验收和交付五个边界各执行一次刷新恢复。
- 对一个零网络异步任务验证安全失败/重试；结果未知时不得创建第二个业务对象或重复计费事实。
- 验证来源变化会进入合同规定的 stale/blocked，只读保留历史，不覆盖已确认版本；若首批执行成本过高，可用同一隔离库中的最小匿名副项目完成，不改原三集主链。
- 验证项目回收/恢复不破坏已生成测试事实；清理 Worker 只处理本轮项目，不检查或删除其他项目对象。

- 正式 React + Fastify + PostgreSQL；桌面至少覆盖 1440×900 与 1024×768、侧栏展开/收起、根页面无横向溢出。
