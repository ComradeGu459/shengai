## 1. 范围与设计判读

这是面向公司内部术语审核人员的高密度 `Operate` 工作台。视觉继承既有冷灰画布、白色工作面、克制靛青、`204px → 72px` 侧栏、`64px` 顶栏和紧凑表格，不建立术语专属配色或另一套应用外壳。

- 设计方差：`3 / 10`，保持稳定、可预测的项目工作台结构。
- 动效强度：`2 / 10`，只使用侧栏开合、侧栏出现和明确状态反馈；不加入装饰动画。
- 视觉密度：`8 / 10`，一屏优先覆盖来源门禁、筛选和 7–8 条候选。
- 主任务：快速处理待确认候选，随时回看真实字幕证据，最终显式创建不可变术语版本。
- 明确非目标：上传页、任务中心、ASR/OCR、视频播放器、字幕正文编辑、管理员密钥页、账号、跨项目学习库。

design-taste-frontend 自身声明不负责数据表格型产品页，本任务只采用它的既有品牌审计和最终预检规则；高密度工作流、状态与表格方法以 Impeccable Operate、`DESIGN.md` 和 M3 契约为准。

## 2. 审计结论与减法

## 3. 正式页面结构

从上到下固定为：

1. 统一顶栏：唯一标题“术语”和服务状态。
2. 项目上下文条：返回项目中心、项目名称/状态、“概览与素材 / 术语”。
3. 来源摘要：公司 SRT 来源、提取状态、待确认、当前模板名称/版本，以及零待确认时唯一“确认并导出”。
4. 页面级来源或失败提示，仅在需要行动时出现。
5. 普通工具栏或选中后的批量栏，两者不同时出现。
6. 紧凑候选表；证据、编辑和新增从右侧侧栏完成。
7. 结果数量与正式排序说明。

| 全部待确认 | 已选择全部 N 项、跨筛选范围、当前模板 | 只保留“全部采用并导出 XLSX”；按采用 → 版本 → 文件顺序，任一失败不创建版本/文件 | 主操作和确认框均可键盘到达；确认框聚焦取消并闭环 |
| 批量局部失败 | 成功数、失败数、未创建版本/文件，失败行有原因 | 成功项保留真实状态，失败项逐项重试；不得给出下载 | 顶部结论为 `role=status`，失败行同时有文字，不只用红色 |
| 零待确认确认导出 | 来源摘要、纳入规则、模板名称/版本、不可变版本号 | 唯一页面主操作为“确认并导出”；后端单一幂等发布命令原子保存版本与导出绑定，未知结果重试不产生半成品 | 初始聚焦取消；Tab 双向闭环；Escape/取消恢复触发项 |
| 公司模板管理 | 当前模板名称/版本、五个固定字段、历史只读列表 | 只改模板名、五字段表头/顺序；保存新版本或保存并启用，不原地覆盖 | 初始聚焦关闭；上下移动可用键盘；Tab 双向闭环；Escape 恢复入口 |

## 5. 全状态文案基线

- 加载：`正在读取术语草稿与来源状态`，保留表头骨架。
- 公司 SRT 未就绪：`还缺 N 集公司 SRT / 第 N 集校验失败`，唯一下一步回到概览与素材。
- 提取运行中：`正在校验第 N / M 集的真实字幕证据，可以离开页面`。
- 提取失败：`第 N 集第 M 轴时间格式无效，请修正公司 SRT 后重试`，附请求标识。
- 空结果：`公司 SRT 已完整扫描，没有提取到可审核术语`，保留人工新增。
- 待确认：`还有 N 项待确认`。
- 来源变化：`公司 SRT 内容已变化，当前草稿保留但不能确认新版本`。
- 项目不可编辑：`术语草稿和已确认版本保持只读，恢复项目后继续`。
- 项目不可编辑、来源已变化或新提取运行时，证据和历史仍可查看，但新增、编辑、选择、批量、逐行裁决、失败重试和发布动作全部不可用；相同限制必须有后端权威门禁。
- 并发修改或版本条件失败：保留用户输入，提示读取最新草稿后重新提交，不静默覆盖。
- 批量局部失败：`全部采用未完成：N 项中 X 项已采用，Y 项失败。未创建 Vn，未生成 XLSX`；成功项保持已保存，失败项逐行显示原因与重试。
- 模板保存失败：保留模板名、表头和顺序草稿，指出空表头、重复/缺失字段或版本条件冲突；不得静默回退到默认模板。
- 模板历史：清楚标注“已启用 / 只读”；启用旧版本只改变当前指针，不改写旧版本或历史导出。

## 6. 响应式与视觉验收

### 1440×900

- 展开侧栏 `204px`，顶部来源摘要保持单行四段；工具栏单行；表格无需内部横滚。
- 一屏可见项目身份、来源门禁、工具栏和 7–8 行候选。
- 证据侧栏宽约 `420px`，覆盖右侧内容但不丢失列表上下文。

### 1024×768

- 侧栏展开与收起均无页面底部横向滚动条；来源摘要折为两行，工具栏允许换行。
- 表格保持约 `1040px` 最小宽度，只在 `.tableWrap` 内横向滚动；主操作和更多操作可通过横滚或键盘到达。
- 侧栏从 `204px` 收到 `72px` 只改变可用宽度，不改变筛选、选择、审核或版本资格。
- 模板窗口最大宽度约 `760px`，内容在窗口内部纵向滚动；不得推动根页面横溢。

### 非颜色单一编码

- 四态均有中文文字、不同语义色和圆点形状标记。
- 来源变化、失败、成功与禁用均有完整句子；按钮下明确当前门禁原因。
- 所有可点击文字保留下划线、按钮边界或焦点环，不只依赖颜色表示可操作。
