## 状态覆盖

三个页面分别提供以下六类可切换状态，共 18 个组合：

- 正常：展示真实任务密度、状态层级和主要操作。
- 加载：使用结构占位，保留页面标题和主要布局。
- 空数据：说明当前没有对象，并提供唯一合理的下一步。
- 失败：展示失败原因、错误码和范围明确的恢复动作。
- 禁用：解释操作不可用的原因，不只依赖按钮灰态。
- 恢复：反馈恢复成功或连接恢复，并说明已保留的进度。

## 契约映射

- 项目工作状态采用 `draft`、`uploading`、`verifying`、`ready`、`blocked` 的展示含义。
- 项目生命周期采用 `active`、`recycled`、`purging`、`purged` 的展示含义。
- “暂停”明确为本机浏览器行为；服务端上传会话仍可处于 `uploading`，不新增服务器暂停状态。
- 回收站保留期固定为 48 小时；`purging` 状态不可恢复，页面不提供即时物理删除或强制恢复入口。
- 上传失败示例采用 `UPLOAD_AUTHORIZATION_EXPIRED`、`UPLOAD_SESSION_EXPIRED`、`FILE_FINGERPRINT_MISMATCH`，分别对应刷新授权并续传、重新创建任务、重新选择原文件。
- 连接恢复后只续传缺失分片，不重复上传已经完成的分片。
